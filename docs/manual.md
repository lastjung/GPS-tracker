# 사용자 매뉴얼

## 지도 조작

- 드래그: 지도 이동
- 휠: 확대/축소

## 시작/끝 선택

- 파란 도로 위를 클릭해 시작/끝 지점을 선택합니다.
- 같은 도로망(연결된 파란 선) 안에서 두 지점을 선택해야 경로가 나옵니다.

## 실행

- `Start` 버튼을 누르면 탐색 애니메이션이 시작됩니다.
- 탐색이 끝나면 최종 경로가 강조 표시됩니다.

## 실패 케이스

- 경로가 나오지 않으면 연결되지 않은 도로망일 수 있습니다.
- 다른 위치(같은 파란 도로 덩어리)에서 다시 선택하세요.

## 설정

- 알고리즘 선택: `A*` / `Dijkstra`
- 탐색 속도: 슬라이더로 조절

## 🎬 유튜브 쇼츠(9:16) 제작 가이드

가운데 9:16 영역만 남기고 나머지를 검게 가리는 **'시네마 모드'**를 통해 전문가 수준의 영상을 만들 수 있습니다.

### 1. 촬영 준비

- **Shorts 모드 활성화**: 메뉴에서 `9:16 Shorts Mode`를 체크합니다. 화면 양옆이 검은색으로 완전히 가려지며 가운데 9:16 영역만 보이는 **'Shorts Theater Mode'**가 시작됩니다.
- **전체화면 사용 (강력 추천)**: 브라우저에서 `F11`(또는 Mac `Cmd + Ctrl + F`)을 눌러 전체화면으로 전환하면, 불필요한 테두리 없이 완벽한 모바일 뷰로 촬영할 수 있습니다.
- **창 크기 조절**:
  - 전체화면이 아닐 때 브라우저 너비 제한으로 창이 더 안 줄어든다면, **창의 높이**를 줄여보세요.
  - 높이가 줄어들면 9:16 비율에 맞춰 가이트 너비도 자동으로 좁아집니다.
- **경로 자동 맞춤 (새 기능)**: 체크박스를 켜거나, `Reset` 옆의 **🎯(과녁) 버튼**을 누르면 시작/끝 지점이 9:16 영역 안에 완벽하게 들어오도록 지도가 자동 조정됩니다.
- **구도 잡기**: 중앙의 밝은 영역 안에 메뉴창과 지도가 잘 들어오도록 배치합니다.

### 2. 녹화 및 실행

- `Record & Start` 버튼을 누릅니다.
- 녹화할 탭 또는 창을 선택합니다.
- 3초 카운트다운 후 알고리즘이 시작되며, **시간과 거리가 실시간으로 업데이트**됩니다.
- 탐색이 완료되면 자동으로 녹화가 종료(1.5초 후)되고 파일이 브라우저의 전용 **[다운로드]** 폴더에 저장됩니다.

### 3. 파일 이동 및 자동 변환

다운로드된 영상을 쇼츠 규격(9:16 MP4)으로 변환하기 위해 파일을 옮겨야 합니다.

1.  PC의 **[다운로드]** 폴더에서 녹화된 `.webm` 파일을 찾습니다.
2.  해당 파일을 프로젝트 폴더 내부의 **`webm/`** 폴더 안으로 직접 **이동**(또는 복사)합니다.
3.  터미널(VS Code 등)에서 아래 명령을 실행합니다.

```bash
# 터미널에서 아래 명령을 실행 (가장 최근 녹화 파일 자동 선택)
sh webm/crop-side-tomp4.sh
```

**변환 결과:**

- 9:16 비율로 좌우 정중앙 자동 크롭 (Pure 9:16)
- 유튜브 업로드용 MP4 파일 생성
