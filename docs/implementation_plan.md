# 구현 계획서 - 토론토 고정 루트 및 코드 정리 (복구됨)

사용자의 요청에 따라 지도의 기본 위치를 토론토로 변경하고, 경로를 동북쪽에서 시앤타워로 고정하며, 지도의 상호작용을 차단했습니다. 또한, 깃 업로드를 위해 불필요한 레거시 코드를 정리했습니다.

## 주요 변경 사항

### 1. 토론토 고정 설정

- `RealMapVisualizer.jsx`에서 기본 도시를 토론토로 설정.
- 동북쪽(Start) -> 시앤타워(End) 고정 루트 적용.
- `isMapLocked: true` 기본값 적용으로 지도 이동 차단.

### 2. 프로젝트 정리 (Cleanup)

- 현재 앱에서 사용하지 않는 `GridVisualizer.jsx`, `MapComponent.jsx` 및 `src/algorithms` 폴더 등 불필요한 파일을 제거하여 깃 업로드용으로 최적화.

### 3. 문서화

- `docs/manual.md`에 현재 설정된 모든 기능과 조작법을 상세히 기록.
- `.gitignore`를 보강하여 불필요한 시스템 파일이 올라가지 않도록 설정.
